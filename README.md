В Клодздец 1.0.22 для Mac и Windows следующие обновления скачиваются и устанавливаются в фоне, без всплывающих окон и запуска браузера. После автоматического перезапуска на Windows приложение доступно в трее рядом с часами, на Mac — в строке меню. В Windows также исправлена загрузка EXE с GitHub. При первом переходе с Mac 1.0.21 прежняя версия ещё может показать окно или открыть браузер.

В версии 1.0.21 для Mac и Windows оценка сохраняется, если за полные 15 секунд проверки у Claude не обнаружено соединений, даже когда приложение открыто. Разные внешние IP тоже сохраняют баллы, если сетевые источники и геобазы подтверждают одну страну выхода.

В Mac и Windows 1.0.20 скачком IP считается подтверждённая смена страны. Изменения адреса внутри страны сохраняются в журнале, а счётчик дней продолжает идти. Проверка обновлений выполняется при запуске и каждый час, включая переход с прежних настроек Mac.

В Windows 1.0.17 исправлен возврат на экран входа после правильного кода из Пачки. Приложение корректно сохраняет 30-дневную сессию и восстанавливает её после перезапуска. Обновление доступно через приложение, в том числе с экрана входа.

В 1.0.16 результаты в закрытую админку отправляются также при входе по персональному токену. Сохраняется совместимость с уже выданными токенами. Отправка выполняется каждый час, при запуске приложения, ручной проверке и подтверждённом изменении IP или страны выхода.

В 1.0.15 приложение автоматически показывает найденную версию, загружает её и перезапускается через 30 секунд после готовности. На Mac текущую установку можно отложить кнопкой «Позже». Перед установкой проверяется подпись и сохраняется журнал. На Mac для перехода с 1.0.14 и прежних версий один раз нажмите «Обновить сейчас».

В 1.0.14 результат отправляется на сервер админки каждый час, при запуске приложения, ручной проверке и подтверждённом изменении IP или страны выхода. Удалена подпись о доступности результата администратору. Исправлены обработка входа и приём результатов, на Mac ограничен размер загружаемых ответов, Windows использует Electron 45.2.3. Сохранённые вход, результаты и журнал продолжают использоваться.

В версии 1.0.12 для Mac и Windows добавлен дневной снимок основного экрана для закрытой админки. Администратор видит те же результаты проверки. При работе приложения отправка выполняется через вход в Пачку Синергиум. Снимок содержит текущие результаты проверки. Windows также получил промежуточные оценки **4−, 3− и 2−** и накопленные изменения интерфейса Mac.

В 1.0.9 исправлено повторное открытие браузера при восстановлении проверки доступа после сна или временного обрыва сети. Ручная проверка доступна по кнопке. Из основного интерфейса убраны имя пользователя и кнопка «Выйти».

Для доступа используется Пачка Синергиум или персональный токен для этого компьютера. Код Пачки приходит в личное сообщение; токен выдаёт администратор. Сохранённый вход и журнал IP остаются на месте, проверка обновлений доступна до входа.

VPN-профили не снижают оценку: если они не найдены, строка зелёная; найденные или недоступные показаны серым. При остальных успешных проверках офисный IP получает 4+, резидентский и мобильный — 5.

Сохранены мобильный Wireless как «Резидентский IP (мобильный)» с золотым кубком, независимая Net.Coffee, офисный IP со звездой и упрощённое меню. Геолокация и разрешения не запрашиваются; приложение не меняет настройки сети.

На Windows скачайте и запустите EXE. На Mac перенесите приложение из DMG в «Программы». Чтобы открыть окно обновления вручную, нажмите на версию внизу меню. На Windows также можно выбрать «Обновления приложения…» в трее, на Mac — «Проверить обновления…» в меню значка приложения. Каналы остаются прежними: `macos/stable` и `windows-portable-v3/stable`. Приложения получают только обновления своей платформы и проверяют криптографическую подпись перед установкой.

**Переход на Windows 1.0.22.** Скачайте EXE из таблицы выше, щёлкните правой кнопкой по значку приложения рядом с часами и выберите «Завершить Клодздец». Если вы запускали portable EXE, замените его скачанным файлом. Для существующего ярлыка сохраните прежние имя и расположение EXE. Затем запустите новый EXE. Журнал, настройки и сохранённый вход хранятся отдельно от файла приложения. Версия 1.0.22 получает следующие обновления автоматически.

Mac подписан Developer ID и прошёл нотарификацию Apple. Windows EXE пока без Authenticode издателя, поэтому SmartScreen может показать предупреждение при первом запуске. Подпись канала обновлений проверяется отдельно.

Репозиторий разработки приватный. Здесь находятся только готовые приложения и каналы; публикация не предоставляет открытой лицензии на исходный код. Диагностические журналы, IP и координаты пользователей сюда не загружаются. При проверке обновлений GitHub видит сетевой адрес соединения; для независимой оценки Net.Coffee получает проверяемый публичный IP Claude.

# Синергиум.Антиблок

Приложение для проверки признаков страны, репутации внешнего IP и изменений сетевого выхода на macOS и Windows.

Этот публичный репозиторий содержит установочные файлы и каналы обновлений. Репозиторий разработки остаётся приватным. Публикация установочных файлов не означает предоставление открытой лицензии на исходный код.

## Скачать

Готовые версии размещаются в [Releases](https://github.com/waseg-kz/sinergium-antiblock-releases/releases).

| Платформа | Требования | Формат |
| --- | --- | --- |
| macOS | macOS 14+, Apple Silicon или Intel | Universal DMG / ZIP |
| Windows | Windows 10/11 x64 | Установщик EXE |

Первая версия с обновлятором устанавливается вручную. Дальше приложение проверяет новые выпуски и предлагает обновление. Перед установкой обновления проверяется его криптографическая подпись.

## Каналы

- `macos/stable` и `windows/stable` — обычные выпуски.
- `macos/beta` и `windows/beta` — тестовые выпуски; используются только тестовыми сборками.

Версии Mac и Windows независимы. Номер последнего релиза всего репозитория не определяет актуальную версию конкретной платформы. Сведения о подписи издателя и известных ограничениях указываются в описании каждого выпуска.

Диагностические журналы, IP-адреса пользователей и координаты сюда не загружаются. Проверка обновлений обращается к GitHub; при этом GitHub видит сетевой адрес соединения.

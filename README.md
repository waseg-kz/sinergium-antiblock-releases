# Клодздец

Приложение для проверки признаков страны, репутации IP и изменений сетевого выхода. Ранее — «Синергиум.Антиблок».

| Windows | Windows 10/11 x64 | [1.0.6 — portable EXE без установки](https://github.com/waseg-kz/sinergium-antiblock-releases/releases/download/windows-portable/v1.0.6/Sinergium-Antiblock-1.0.6-Windows-x64-Portable.exe) |

В 1.0.6 сохранённые дни без скачков IP остаются видны после перезапуска и при ошибках проверки. До новых ответов показана статистика «по журналу» с датой. Mac перед установкой заново проверяет последнюю версию, чтобы не использовать устаревшее предложение промежуточного обновления.

Сохранены мобильный Wireless как «Резидентский IP (мобильный)» с золотым кубком, независимая Net.Coffee, офисный IP со звездой и упрощённое меню. Геолокация и разрешения не запрашиваются; приложение не меняет настройки сети.

На Windows скачайте и запустите EXE. На Mac перенесите приложение из DMG в «Программы». Для проверки обновлений нажмите версию внизу меню; установка начинается по вашему действию. Каналы остаются прежними: `macos/stable` и `windows-portable-v3/stable`. Приложения получают только обновления своей платформы и проверяют криптографическую подпись перед установкой.

Прежние версии Windows portable поколения v3 обновляются через приложение. Со старой линии v2 или NSIS требуется однократная ручная замена: завершите старое приложение через трей и запустите новый EXE. Журнал сохраняется.

Mac подписан Developer ID и прошёл нотарификацию Apple. Windows EXE пока без Authenticode издателя, поэтому SmartScreen может показать предупреждение при первом запуске. Подпись канала обновлений проверяется отдельно.

Репозиторий разработки приватный. Здесь находятся только готовые приложения и каналы; публикация не предоставляет открытой лицензии на исходный код. Диагностические журналы, IP и координаты пользователей сюда не загружаются. При проверке обновлений GitHub видит сетевой адрес соединения; для независимой оценки Net.Coffee получает проверяемый публичный IP Claude.
